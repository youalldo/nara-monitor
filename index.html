처음 한 번만 설정하면 됩니다

  1. 공공데이터포털에서 API 3개 활용신청 (무료, 대부분 바로 승인)
    • 조달청_나라장터 입찰공고정보서비스 — 포털에서 이 이름으로 검색
    • 조달청_나라장터 사전규격정보서비스 ↗
    • 조달청_나라장터 발주계획현황서비스 ↗
  2. 마이페이지 → 개발계정에서 일반 인증키(Decoding)를 복사해 아래에 붙여넣기

    키는 이 브라우저에만 저장되고 공공데이터포털 외에는 어디에도 보내지 않습니다. 활용신청 직후에는 키가 반영되기까지 1~2시간 걸릴 수 있습니다.

자료: 조달청 나라장터 Open API (공공데이터포털). 공고명 키워드로 자동 선별한 목록이므로 참가 전 반드시 나라장터 원문을 확인하세요. 사전규격·발주계획은 상세 링크가 제공되지 않아, 상세 정보의 번호를 복사해 나라장터에서 검색하면 됩니다.

설정

공공데이터포털 서비스키

이 브라우저에만 저장됩니다. 다른 PC·브라우저에서는 다시 입력하거나 아래 '설정 옮기기'를 쓰세요.

검색 키워드

사업명(공고명)에 하나라도 들어 있으면 수집합니다. 띄어쓰기는 무시합니다. 쉼표로 여러 개를 한 번에 넣을 수 있습니다.

제외어

엉뚱하게 걸리는 공고를 거릅니다. 제외어 부분을 지운 뒤에도 키워드가 남으면 정상 수집합니다. 예) 환경영향 → '환경영향평가'가 '경영'에 걸리는 것은 막고, '중장기 경영전략 및 환경영향평가'는 그대로 수집.

업무구분

우리 회사 (참가자격 판정)

입찰공고마다 업종(면허)·지역 제한을 조회해 아래 정보와 비교합니다. 추정가격 1억 원(부가세 포함 1.1억) 미만은 소기업·소상공인 제한으로 추정해 따로 분류합니다.
