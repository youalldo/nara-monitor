# 나라장터 키워드 모니터 (웹 버전)

나라장터의 **입찰공고 · 사전규격 · 발주계획** 중 사업명에 관심 키워드(기본: 경영·전략·중장기·조직·성과·평가)가 들어간 공고를 모아 보여 주는 웹 페이지입니다.

- **설치가 필요 없습니다.** 주소를 즐겨찾기해 두고 열기만 하면 됩니다. 파이썬도, 압축 파일도 필요 없습니다.
- 기능이 바뀌면 이 저장소가 갱신되고, 사용자는 **새로고침만** 하면 바로 반영됩니다.
- 화면을 열면 마지막 조회 이후 올라온 공고를 **자동으로 조회**하고, 새 공고에는 **NEW** 표시가 붙습니다.
- 키워드·제외어는 화면의 **[설정]** 에서 바로 추가(Enter)·삭제(×)합니다.
- 공고마다 **참가자격(금액·업종·지역)을 자동 판정**해, 참가할 수 없는 공고는 기본으로 숨깁니다.
- **공고문 자동 AI 분석**: GitHub 서버가 평일 하루 3번 새 공고의 공고문·제안요청서를 내려받아 AI(Claude)로 읽고, 평가비율·정량점수·과업내용·기업규모 제한을 검토양식 칸에 채워 둡니다. 화면을 열면 결과가 자동으로 붙습니다.
- 결과는 **검토양식 엑셀**(업데이트날짜~본공고 확인까지 18개 항목) 또는 CSV 로 내려받을 수 있습니다.

## 처음 사용할 때 (1회)

1. [공공데이터포털](https://www.data.go.kr)에서 아래 3개 API를 각각 **활용신청** 합니다. (무료, 대부분 바로 승인)
   - `조달청_나라장터 입찰공고정보서비스` (포털에서 이름으로 검색)
   - [조달청_나라장터 사전규격정보서비스](https://www.data.go.kr/data/15129437/openapi.do)
   - [조달청_나라장터 발주계획현황서비스](https://www.data.go.kr/data/15129462/openapi.do)
2. **마이페이지 → 개발계정** 에서 **일반 인증키(Decoding)** 를 복사합니다.
3. 이 웹 페이지를 열고 첫 화면의 입력칸에 키를 붙여넣은 뒤 **[저장하고 조회 시작]** 을 누릅니다.
   - 활용신청 직후에는 키가 반영되기까지 1~2시간 걸릴 수 있습니다.
   - **[설정] → [연결 점검]** 으로 3개 API가 모두 정상인지 확인할 수 있습니다.

## 사용법

| 하고 싶은 일 | 방법 |
|---|---|
| 새 공고 보기 | 페이지를 열면 자동 조회 (마지막 조회 후 1시간이 지났을 때). 바로 보려면 **[지금 조회]** |
| 지난 공고 다시 찾기 | 오른쪽 위 기간 선택(오늘·3일·7일·14일·30일) 후 **[지금 조회]** |
| 키워드 추가·삭제 | **[설정]** → 입력칸에 쓰고 Enter (쉼표로 여러 개) / 키워드 옆 **×** → **[저장]** |
| 새 키워드로 지난 공고 찾기 | 키워드를 추가하고 저장하면 나오는 **[최근 7일 다시 조회]** |
| 엉뚱한 공고 거르기 | **[설정] → 제외어** 에 단어 추가 (아래 설명) |
| 검토양식으로 받기 | 목록 위 **[검토양식 엑셀]** — 기존 '용역리서칭' 시트와 같은 열 순서라 그대로 붙여넣을 수 있음 (지금 화면에 보이는 목록 기준) |
| 공고문 AI 분석 결과 보기 | 카드의 **AI 분석** 줄(평가비율·기업규모 판단) → **상세 정보** 를 펼치면 정량점수·과업내용 등 전체. 분석된 공고만 보려면 **'AI 분석된 것만'** |
| 1억 미만 사업도 보기 | 목록 위 참가자격 선택에서 **'+ 1억 미만(소기업 제한 추정)도'** |
| 다른 PC에서 같은 설정 쓰기 | **[설정] → 설정 복사** → 다른 PC에서 **설정 붙여넣기** |

**제외어 동작**: 제외어 부분을 지운 뒤에도 키워드가 남으면 정상 수집하고, 남지 않으면 '제외'로 표시합니다.

- `소규모 환경영향평가 용역` → '경영'(환**경영**향)과 '평가'가 모두 제외어 안에 있었음 → 제외
- `중장기 발전전략 및 환경영향평가` → 제외어를 지워도 '중장기'·'전략'이 남음 → 정상 수집

제외된 공고도 지우지 않으며, 목록 위 **'제외 항목 보기'** 를 켜면 볼 수 있습니다.

## 참가자격 판정

각 공고 카드에 배지가 붙고, **상세 정보 · 참가자격 판단**을 펼치면 근거가 나옵니다.

| 배지 | 기준 |
|---|---|
| 참가 가능 | 추정가격 1억 원 이상(부가세 포함 1.1억 이상) + 업종·지역 제한을 충족 |
| 확인 필요 | 실적제한·지정경쟁, 지역제한인데 회사 소재지 미설정, 업종·지역 조회 실패, 금액 미공개 |
| 1억 미만·소기업 제한 추정 | 추정가격 1억 원 미만 → 판로지원법상 소기업·소상공인 제한일 가능성이 큼 (기본 숨김) |
| 참가 불가 | 요구 업종을 보유하지 않았거나, 참가 가능 지역에 회사 소재지가 없음 (기본 숨김) |

- 입찰공고는 나라장터의 **면허(업종)제한·참가가능지역** 정보를 공고마다 조회해 **[설정] → 우리 회사** 의 업종코드·소재지와 비교합니다. (공고당 API 2회, 한 번 확인한 공고는 다시 부르지 않음)
- 사전규격·발주계획은 업종·지역 정보가 없어 **금액 기준으로만** 판정합니다. 사전규격 배정예산·발주금액은 부가세 포함으로 보고 1.1로 나눠 비교합니다.
- 1억 미만인데 소기업 제한이 없는 예외 공고, 평가비율·정량점수·과업내용은 공고문·제안요청서에만 있습니다. 아래 **공고문 자동 AI 분석**이 이 내용을 채우고, 분석되지 않은 공고는 검토양식의 해당 칸을 비워 둔 채 '본공고 확인/소상공인 확인' 칸에 확인할 점을 적어 둡니다.

## 공고문 자동 AI 분석 (서버)

이 저장소의 GitHub Actions 가 **평일 07:40 · 12:40 · 18:40(한국시간)** 에 자동으로 실행됩니다.

1. `analysis-config.json` 의 키워드로 최근 입찰공고·사전규격(용역)을 조회
2. 참가자격 판정 — **참가 불가**(업종·지역 미충족)는 건너뜀. **1억 미만**은 '중기업 참가 가능한 예외 공고'를 찾기 위해 분석
3. 첨부파일(공고문·제안요청서·과업지시서, e발주 첨부 포함)을 내려받아 글자 추출 — HWP(5.0)·HWPX·DOCX·TXT·ZIP 안 파일, PDF 는 그대로
4. Claude 가 검토양식 칸(평가비율·정량점수·과업기간·접수구분·마감일정·참가범위·과업내용·고려사항·기업규모 제한과 근거 문구)을 채워 `data/reviews.json` 에 저장
5. 웹 화면은 열 때마다 이 결과를 읽어 카드·상세 정보·검토양식 엑셀에 반영합니다. 공고문에서 '중소기업·소상공인 확인서'처럼 중기업 참가 가능 문구를 찾으면 1억 미만 공고도 **참가 가능**으로, '소기업·소상공인만'이면 **참가 불가**로 바뀝니다.

### 처음 한 번 설정

1. [Anthropic Console](https://console.anthropic.com/settings/keys)에서 API 키를 만들고 **Billing** 에 결제 수단을 등록합니다. 이 용도 전용 키를 만들고 **월 지출 한도**를 걸어 두기를 권합니다.
2. 이 저장소의 [Settings → Secrets and variables → Actions](https://github.com/youalldo/nara-monitor/settings/secrets/actions/new)에서 **New repository secret** 으로 두 개를 등록합니다.
   - `G2B_SERVICE_KEY` — 공공데이터포털 일반 인증키(Decoding), 화면에 넣은 것과 같은 키
   - `ANTHROPIC_API_KEY` — 위에서 만든 Claude API 키
3. [Actions → 공고문 AI 분석](https://github.com/youalldo/nara-monitor/actions/workflows/analyze.yml) → **Run workflow** 를 누릅니다. (Actions 탭에서 워크플로 사용 확인 버튼이 나오면 먼저 눌러 켭니다.) 5~15분 뒤 웹 화면을 새로고침하면 결과가 보입니다.

웹 화면 **[설정] → 서버 자동 AI 분석** 에 마지막 실행 시각, 분석·대기·실패 건수, 이번 달 비용이 나오고, 위 링크로 바로 갈 수 있습니다.

### 분석 설정 바꾸기

서버는 웹 화면의 설정이 아니라 저장소의 **`analysis-config.json`** 으로 분석합니다. 화면에서 키워드·제외어·업종코드를 바꿨다면:
**[설정] → 화면 설정을 분석 설정으로 복사** → **분석 설정 고치기 ↗** → 내용을 모두 지우고 붙여넣기 → **Commit changes**.

| 항목 | 뜻 |
|---|---|
| `analyzeSmall` | `true` 면 1억 미만 공고도 분석해 예외 공고를 찾음. 비용을 줄이려면 `false` |
| `maxAnalysesPerRun` | 한 번 실행에 분석할 최대 공고 수 (기본 10). 넘친 공고는 다음 실행에 분석 |
| `maxAttempts` | 첨부를 못 받거나 오류가 난 공고를 다시 시도할 횟수 (기본 3) |

### 비용과 한계

- **비용**: Claude Opus 5.5, 공고 한 건(공고문+제안요청서)에 보통 0.1~0.4달러. 한 공고는 한 번만 분석합니다. 실행당 최대 10건 × 하루 3번이라 **하루 최대 약 30건**(최악의 경우 하루 약 12달러)이고, 실제로는 키워드에 걸리고 참가 가능한 새 공고 수만큼만 듭니다. GitHub Actions 는 공개 저장소라 무료입니다.
- **첨부파일 내려받기**: GitHub 서버는 해외에 있습니다. 나라장터가 해외 접속의 파일 내려받기를 막으면 카드에 **'서버 AI 분석 실패: 파일 대신 웹페이지가 왔습니다'** 가 표시됩니다. 이 경우 회사 PC 를 실행기(self-hosted runner)로 쓰는 방식으로 바꿔야 합니다.
- 배포용(보기 전용)·암호 HWP 는 글자를 꺼낼 수 없어 그 파일은 건너뜁니다. 같은 공고의 다른 파일(PDF 등)이 있으면 그것으로 분석합니다.
- **공개 범위**: 저장소가 공개라 `analysis-config.json`(키워드·업종코드·소재지)과 `data/reviews.json`(공고 요약)도 누구나 볼 수 있습니다. 공고 내용은 원래 공개 정보이고, **API 키는 Secrets 에만 있어 보이지 않습니다.** 작성자 이름은 서버로 보내지 않습니다.
- AI 가 문서를 잘못 읽을 수 있습니다. 입찰 전 정량점수·참가자격은 원문으로 한 번 더 확인하세요.

## 알아 둘 점

- **저장 위치**: 화면에 넣은 서비스키·설정·조회한 공고는 **이 브라우저 안에만** 저장되고, 공공데이터포털(apis.data.go.kr) 호출에만 키를 씁니다. 서버 자동 분석은 저장소 Secrets 에 따로 등록한 키를 씁니다. 브라우저 방문 기록·사이트 데이터를 지우면 화면 쪽 기록은 지워지지만, 서버 분석 결과는 다시 불러옵니다.
- **호출 한도**: 공공데이터포털 개발계정은 API별 하루 1,000회입니다. 한 번 조회에 보통 3~10회를 쓰고, 화면 위에 오늘 사용량이 표시됩니다.
- **상세 링크**: 입찰공고는 나라장터 상세 화면으로 바로 연결됩니다. 사전규격·발주계획은 API가 상세 주소를 주지 않아, 상세 정보의 번호 옆 **[복사]** 를 눌러 나라장터에서 검색하면 됩니다.
- 공고명 키워드로 자동 선별한 목록입니다. 참가 전 반드시 나라장터 원문을 확인하세요.

| 화면에 나온 내용 | 원인과 해결 |
|---|---|

| `연결 실패` | 인터넷 연결 확인. 회사망이라면 보안 정책으로 `apis.data.go.kr` 접속이 막혀 있을 수 있음 → 전산 담당자에게 허용 요청 |

## 개발자용

- 화면은 순수 HTML/CSS/JavaScript, 빌드 과정 없음. GitHub Pages(루트 폴더)로 배포합니다.
  - `js/core.js` API 호출·응답 해석·키워드·참가자격 판정 (브라우저/Node 공용) · `js/app.js` 화면 · `js/store.js` 저장(IndexedDB/localStorage) · `js/demo.js` 예시 데이터
  - 서버 분석 결과는 `https://raw.githubusercontent.com/<owner>/<repo>/main/data/reviews.json` 에서 읽습니다 (Pages 재배포를 기다리지 않음). 실패하면 같은 경로의 `data/reviews.json`.
- 서버 분석은 Node 22 (`.github/workflows/analyze.yml` → `server/analyze.js`)
  - `js/docread.js` HWP·HWPX·DOCX·TXT·ZIP 글자 추출 · `js/ai.js` Claude 요청(공식 SDK `@anthropic-ai/sdk`, 구조화 출력 JSON 스키마)
  - 내 PC 에서 돌려 보기: `npm ci` 후 `G2B_SERVICE_KEY=... ANTHROPIC_API_KEY=... node server/analyze.js`
- 테스트: 저장소 폴더에서 `npm ci` 후 `node --test` (나라장터·첨부파일·Claude 는 가짜 응답으로 시험)
- 배포 후 브라우저 캐시 때문에 옛 파일이 보이지 않도록, 바꿀 때마다 `index.html` 의 `?v=` 값과 `js/app.js` 의 `VERSION` 을 올립니다.
- `vendor/xlsx-0.18.5.full.min.js` 는 SheetJS Community Edition (Apache-2.0, `vendor/xlsx-LICENSE.txt`) — 화면에서는 엑셀 버튼을 누를 때만 불러오고, 서버는 HWP(OLE) 읽기에 씁니다.
