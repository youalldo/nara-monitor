# 나라장터 키워드 모니터 (웹 버전)

나라장터의 **입찰공고 · 사전규격 · 발주계획** 중 사업명에 관심 키워드(기본: 경영·전략·중장기·조직·성과·평가)가 들어간 공고를 모아 보여 주는 웹 페이지입니다.

- **설치가 필요 없습니다.** 주소를 즐겨찾기해 두고 열기만 하면 됩니다. 파이썬도, 압축 파일도 필요 없습니다.
- 기능이 바뀌면 이 저장소가 갱신되고, 사용자는 **새로고침만** 하면 바로 반영됩니다.
- 화면을 열면 마지막 조회 이후 올라온 공고를 **자동으로 조회**하고, 새 공고에는 **NEW** 표시가 붙습니다.
- 키워드·제외어는 화면의 **[설정]** 에서 바로 추가(Enter)·삭제(×)합니다.
- 결과는 **엑셀·CSV** 로 내려받을 수 있습니다.

## 처음 사용할 때 (1회)

1. [공공데이터포털](https://www.data.go.kr)에서 아래 3개 API를 각각 **활용신청** 합니다. (무료, 대부분 바로 승인)
   - `조달청_나라장터 입찰공고정보서비스` (포털에서 이름으로 검색)
   - [조달청_나라장터 사전규격정보서비스](https://www.data.go.kr/data/15129437/openapi.do)
   - [조달청_나라장터 발주계획현황서비스](https://www.data.go.kr/data/15129462/openapi.do)
2. **마이페이지 → 개발계정** 에서 **일반 인증키(Decoding)** 를 복사합니다.
3. 이 웹 페이지를 열고 첫 화면의 입력칸에 키를 붙여넣은 뒤 **[저장하고 조회 시작]** 을 누릅니다.
   - 활용신청 직후에는 키가 반영되기까지 1~2시간 걸릴 수 있습니다.
   - **[설정] → [연결 점검]** 으로 3개 API가 모두 정상인지 확인할 수 있습니다.

## 사용법

| 하고 싶은 일 | 방법 |
|---|---|
| 새 공고 보기 | 페이지를 열면 자동 조회 (마지막 조회 후 1시간이 지났을 때). 바로 보려면 **[지금 조회]** |
| 지난 공고 다시 찾기 | 오른쪽 위 기간 선택(오늘·3일·7일·14일·30일) 후 **[지금 조회]** |
| 키워드 추가·삭제 | **[설정]** → 입력칸에 쓰고 Enter (쉼표로 여러 개) / 키워드 옆 **×** → **[저장]** |
| 새 키워드로 지난 공고 찾기 | 키워드를 추가하고 저장하면 나오는 **[최근 7일 다시 조회]** |
| 엉뚱한 공고 거르기 | **[설정] → 제외어** 에 단어 추가 (아래 설명) |
| 엑셀로 받기 | 목록 위 **[엑셀]** / **[CSV]** (지금 화면에 보이는 목록 기준) |
| 다른 PC에서 같은 설정 쓰기 | **[설정] → 설정 복사** → 다른 PC에서 **설정 붙여넣기** |

**제외어 동작**: 제외어 부분을 지운 뒤에도 키워드가 남으면 정상 수집하고, 남지 않으면 '제외'로 표시합니다.

- `소규모 환경영향평가 용역` → '경영'(환**경영**향)과 '평가'가 모두 제외어 안에 있었음 → 제외
- `중장기 발전전략 및 환경영향평가` → 제외어를 지워도 '중장기'·'전략'이 남음 → 정상 수집

제외된 공고도 지우지 않으며, 목록 위 **'제외 항목 보기'** 를 켜면 볼 수 있습니다.

## 알아 둘 점

- **저장 위치**: 서비스키·설정·조회한 공고는 **이 브라우저 안에만** 저장됩니다. 서버나 이 저장소로는 보내지 않으며, 공공데이터포털(apis.data.go.kr) 호출에만 키를 씁니다. 브라우저 방문 기록·사이트 데이터를 지우면 함께 지워집니다.
- **호출 한도**: 공공데이터포털 개발계정은 API별 하루 1,000회입니다. 한 번 조회에 보통 3~10회를 쓰고, 화면 위에 오늘 사용량이 표시됩니다.
- **상세 링크**: 입찰공고는 나라장터 상세 화면으로 바로 연결됩니다. 사전규격·발주계획은 API가 상세 주소를 주지 않아, 상세 정보의 번호 옆 **[복사]** 를 눌러 나라장터에서 검색하면 됩니다.
- 공고명 키워드로 자동 선별한 목록입니다. 참가 전 반드시 나라장터 원문을 확인하세요.

## 문제 해결

| 화면에 나온 내용 | 원인과 해결 |
|---|---|
| `[코드 30] SERVICE_KEY_IS_NOT_REGISTERED_ERROR` | 키 오타, 또는 그 API를 활용신청하지 않음. 신청 직후라면 1~2시간 뒤 다시 시도 |
| `[코드 20] 서비스 접근 거부` | 활용신청이 아직 승인되지 않음 → 공공데이터포털 마이페이지에서 확인 |
| `[코드 22]` | 오늘 호출 한도 초과 → 내일 다시 |
| `연결 실패` | 인터넷 연결 확인. 회사망이라면 보안 정책으로 `apis.data.go.kr` 접속이 막혀 있을 수 있음 → 전산 담당자에게 허용 요청 |

## 개발자용

- 순수 HTML/CSS/JavaScript, 빌드 과정 없음. GitHub Pages(루트 폴더)로 배포합니다.
- `js/core.js` API 호출·응답 해석·키워드 판정 (브라우저/Node 공용) · `js/app.js` 화면 · `js/store.js` 저장(IndexedDB/localStorage) · `js/demo.js` 예시 데이터
- 테스트: `node --test tests/core.test.js`
- 배포 후 브라우저 캐시 때문에 옛 파일이 보이지 않도록, 바꿀 때마다 `index.html` 의 `?v=` 값과 `js/app.js` 의 `VERSION` 을 올립니다.
- `vendor/xlsx-0.18.5.full.min.js` 는 SheetJS Community Edition (Apache-2.0, `vendor/xlsx-LICENSE.txt`) — 엑셀 버튼을 누를 때만 불러옵니다.
